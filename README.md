## 项目简介

AI Quant Trading System 是一个 **实盘级大模型驱动智能交易框架**。系统彻底解耦了 AI 的“市场认知”与“交易执行”，将大模型严格限制在 **可交易候选池** 内进行决策，配合多层级风控体系与经验记忆层，实现 **安全可控、动态进化、可回测验证** 的自动化交易闭环。

**核心理念**：让 AI 做它擅长的（模式识别与逻辑推演），让代码做它该做的（风控拦截与精确执行）。

---

## 核心特性

| 特性 | 说明 |
|:---|:---|
| **认知与执行解耦** | AI 观察全市场，但**只能**从系统筛选的“候选池”中挑选标的，彻底杜绝幻觉越权交易。 |
| **动态防守线** | 盈利 < 3% 时保本止损，盈利 >= 3% 时自动切换为移动止盈。单向锚定，利润不回吐。 |
| **S 级硬风控** | T+1 限制、硬止损（主板 -5% / 创业板 -7%）、跌停保护等规则写死在底层，优先级永远高于 AI。 |
| **双线程决策** | 交易 AI（90s 高频盯盘） + 研究 AI（30min 深度复盘），独立运行互不阻塞。 |
| **连续仓位调节** | Score 决定基础仓位，Mood 微调 ±20%，Winrate 连续缩放（0.4~1.1），系统永不锁死。 |
| **经验记忆层** | 每日自动复盘沉淀 Mistakes 与 Thesis Stats，次日盘前自动注入 Prompt，拒绝重复踩坑。 |
| **代码数据分离** | 交易数据、配置、日志独立存放于 `/user_data`，升级版本绝不丢失资产。 |
| **全模型兼容** | 内置 JSON 栈平衡提取引擎，完美适配 GPT-4、DeepSeek、Qwen、Kimi 等所有 OpenAI 兼容接口。 |

## 系统架构

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                          数据采集层 (Data Layer)                            │
│  腾讯 API (实时行情)  │  新浪 API (全市场列表)  │  东方财富 API (新闻/资金流)  │
└──────────────────────┬──────────────────────────────────────────────────────┘
                       ↓
┌─────────────────────────────────────────────────────────────────────────────┐
│                     市场结构压缩层 (Structure)                              │
│  板块聚合 -> 龙头识别 -> 情绪阶段判断 (冰点/退潮/升温/高潮)                 │
└──────────────────────┬──────────────────────────────────────────────────────┘
                       ↓
┌─────────────────────────────────────────────────────────────────────────────┐
│                       双 AI 分析引擎 (AI Engine)                            │
│  [交易 AI] 90s/次 -> 输出买卖信号与评分                                      │
│  [研究 AI] 30min/次 -> 深度复盘、排雷、策略建议                             │
└──────────────────────┬──────────────────────────────────────────────────────┘
                       ↓
┌─────────────────────────────────────────────────────────────────────────────┐
│                   动态仓位引擎 (Dynamic Position)                           │
│  基础仓位(Score) x 情绪系数(Mood) x 胜率因子(Winrate) -> 连续缩放           │
└──────────────────────┬──────────────────────────────────────────────────────┘
                       ↓
┌─────────────────────────────────────────────────────────────────────────────┐
│                    风控路由引擎 (Risk Engine) - 最高优先级                  │
│  S级(绝对红线) -> A级(策略控制) -> B级(技术退出) -> 一票否决权               │
└──────────────────────┬──────────────────────────────────────────────────────┘
                       ↓
┌─────────────────────────────────────────────────────────────────────────────┐
│                      执行与记忆层 (Execution)                               │
│  下单执行 -> 更新持仓 -> 写入历史 -> 盘后归档(经验层自进化)                  │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 快速开始

### 1. 环境要求

- Python >= 3.10
- 支持所有 OpenAI 兼容 API（GPT-4、DeepSeek、Qwen、Kimi 等）
- Windows / Linux / macOS 均可运行

### 2. 安装依赖

```bash
git clone https://github.com/YOUR_USERNAME/ai-quant-trading-system.git
cd ai-quant-trading-system
pip install -r requirements.txt
```

### 3. 配置 AI 模型

打开 `user_data/ai_config.json`，填入你的 API 配置：

```json
{
  "api_url": "https://api.deepseek.com/v1/chat/completions",
  "api_key": "sk-your-api-key-here",
  "model": "deepseek-chat",
  "temperature": 0.3,
  "max_tokens": 8192
}
```

### 4. 启动系统

双击 `start.bat` 或在终端执行：

```bash
python v3_main.py auto
```

系统默认开启 **模拟盘**（初始资金 20,000），空仓启动，无需实盘资金即可完整体验全流程。

**访问控制台**：`http://localhost:8503`

## 核心模块说明

| 模块 | 路径 | 核心职责 |
|:---|:---|:---|
| **AI 适配层** | `ai-trader/v2/ai_model.py` | 全模型兼容路由器，支持 JSON 模式、自动重试、栈平衡提取 |
| **事件总线** | `ai-trader/v3/event_bus.py` | 双线程调度中枢，交易/研究 AI 路由，盘前/盘中/盘后策略管理 |
| **风控引擎** | `ai-trader/v2/risk_engine.py` | S/A/B 三级拦截，动态防守线计算，信念值动态衰减 |
| **市场结构** | `ai-trader/v3/market_structure.py` | 情绪周期判定，板块强度与资金流向量化，龙头识别 |
| **经验记忆层** | `ai-trader/v3/experience_layer.py` | 历史胜率统计、错误模式归档、次日策略自动注入 |
| **Web 控制台** | `trading-dashboard/` | 实时持仓看板、收益曲线、AI 思考日志、配置热更新 |

## 交易逻辑流水线

1. **全市场数据** (腾讯/新浪/东财)
2. **结构建模** & 情绪打分
3. **提取可交易候选池**
4. **AI 隔离决策** (生成信号 & 信念值)
5. **动态防守线计算** (保本态 / 锁利态)
6. **S 级风控过滤** (T+1 / 止损 / 跌停)
7. **动态仓位计算** (情绪 x 胜率 x Score)
8. **执行下单** & 记录
9. **盘后复盘归档** (更新经验库)

## 升级与数据安全

本系统采用 **代码与数据分离架构**，确保升级版本时交易资产绝对安全。

### 目录结构

```text
AI-Trading-System/
├── ai-trader/              # 纯代码（可随时覆盖升级）
├── trading-dashboard/      # 纯前端代码
├── user_data/              # [受保护] 交易数据与配置
│   ├── ai_config.json      # API 配置
│   ├── portfolio.json      # 账户状态
│   ├── trading_history.db  # 历史交易
│   └── ai_trade.log        # 运行日志
├── v3_main.py
└── start.bat
```

### 如何安全升级

1. 下载最新代码包。
2. **不要删除** 你原有的 `user_data` 文件夹。
3. 将新包里的 `.py` 代码和前端文件覆盖到旧目录。
4. 保留 `user_data/` 不动。
5. 直接运行 `start.bat`，系统自动读取旧数据无缝继续。

> 提示：双击 `update.bat` 可一键自动备份数据并提示升级。
