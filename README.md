AI量化交易系统V9.0 官方技术文档
1. 项目概述
本项目是基于Python开发的全流程、高稳定性、双AI架构A股智能量化交易系统，适配A股主板、创业板、科创板全市场交易标的。系统采用事件驱动核心架构，搭载双AI智能分析引擎、S/A/B三级风控熔断机制、自研动态仓位算法与持仓信念评估系统，实现行情采集、市场解析、智能决策、风险校验、交易执行、数据持久化、可视化监控全链路自动化运行。
系统核心设计遵循AI辅助决策、风控优先裁决、无情绪化交易原则，区分实时交易模型与深度复盘模型，各司其职、物理隔离，彻底解决传统量化系统信号混乱、风控缺失、仓位僵化、策略无法迭代等痛点，可稳定适配震荡、上涨、下跌、结构性分化等全品类A股行情。
2. 核心技术架构
系统采用七层分层架构设计，层层校验、逐级流转，所有交易信号必须完成全层级校验方可执行，保障交易稳定性与安全性。
2.1 整体架构分层
1. 数据采集层：整合多源正规行情API、财经资讯数据，搭配本地内存缓存与文件快照，实现全市场行情秒级更新、资讯实时抓取，保障数据来源全面、稳定、低延迟。
2. 市场解析层：自动完成板块聚合、题材归类、龙头个股识别、资金流向研判、市场情绪周期判定，将海量原始行情数据压缩为结构化、可解析的市场状态摘要，为AI决策减负。
3. 双AI智能分析层：搭载独立交易AI与研究AI双模型，分工协作、互不干扰，分别负责高频实时决策与低频深度复盘。
4. 动态仓位计算层：自研三维动态仓位算法，结合AI评分、市场情绪、历史交易胜率智能调节下单仓位，摒弃传统固定仓位模式。
5. 多级风控裁决层：S/A/B三级风控体系，拥有最高一票否决权，拦截所有不符合规则的交易信号，从根源规避交易风险。
6. 交易执行层：标准化交易下单、手数换算、状态更新、日志记录、数据库持久化，保障每一笔交易可追溯、可复盘。
7. 可视化监控层：轻量化Web可视化面板，支持动态配置参数、实时展示持仓、盈亏、交易记录与系统运行状态。
2.2 双AI分离架构（核心核心亮点）
1. 高频交易AI（90秒轮询）：轻量化推理逻辑，高频扫描全市场资金异动、走势变化、板块轮动，快速输出标准化买入、持有、卖出信号，适配短线高频交易场景，响应速度毫秒级。
2. 深度研究AI（30分钟轮询）：大模型深度复盘逻辑，定期复盘交易记录、统计策略胜率、排查交易漏洞、优化Prompt策略、挖掘市场主线题材，实现策略自主迭代优化。
3. 双层Prompt认知架构：第一层完成全市场全景认知，判定当日市场情绪与主线方向；第二层精准筛选可交易标的，过滤高位风险标的、低流动性个股，解决AI选股偏差问题。
3. 核心功能模块详解
3.1 S/A/B三级风控系统（最高优先级）
风控为系统最高裁决单元，所有AI交易信号必须逐级通过S、A、B三级校验，任意层级拦截则终止交易，杜绝非理性、高风险交易行为。
3.1.1 S级红线风控（绝对强制规则，不可突破）
包含A股T+1交易限制、分级硬止损机制（主板-5%、创业板-7%、科创板-8%）、跌停价格拦截保护、买入持仓保护期、卖出冷静期、异常行情熔断、锁仓保护等硬性规则，从底层杜绝重大亏损与违规交易。
3.1.2 A级策略风控（策略优化规则）
根据市场情绪周期动态限制整体仓位，设置题材龙头与普通个股分级准入评分门槛，执行阶梯式分批止盈策略，过滤弱势趋势行情，优化整体交易胜率与收益曲线。
3.1.3 B级技术风控（细节纠错规则）
实现持仓超时强制轮换、技术破位止损、冲高回落止盈、放量滞涨离场、缩量弱势标的过滤等精细化风控，修正AI决策细节偏差，规避技术性亏损。
3.2 自研动态仓位引擎V2.0
采用「AI核心评分+市场情绪系数+历史胜率微调」三维动态算法，彻底解决传统固定仓位、乘法模型锁死、仓位失衡等行业痛点。系统根据标的评分划分多档基础仓位，结合当日市场冷暖动态缩放，依托历史交易胜率微调下单比例，同时以个股数量（股数）为核心下单单位，规避A股最小交易单位限制，保障订单100%可成交。
3.3 Conviction动态持仓信念系统
系统为每一笔独立持仓生成0-100分动态信念分值，初始默认60分，根据标的题材强度、资金流向、走势结构、板块联动情况实时动态加减分。当信念分值低于30分时，系统强制触发清仓指令，彻底杜绝人工交易中扛单、不止损、侥幸持仓等情绪化交易问题。同时每笔交易绑定入场逻辑与失效条件，逻辑破位即离场，交易逻辑闭环可控。
3.4 全功能Web可视化监控面板
内置轻量化本地Web服务，无需服务器部署、无需复杂配置。前端支持动态配置大模型API密钥，无需修改后端代码；实时展示系统运行状态、当前持仓明细、历史交易记录、盈亏统计曲线、AI分析日志、市场情绪数据，界面简洁直观，运维与复盘零门槛。
3.5 全场景A股交易适配
全面兼容A股主板、创业板、科创板所有合规交易标的，支持盘中实时竞价交易、尾盘套利交易，同时适配创业板、科创板15:05-15:30盘后固定价格交易，覆盖A股全部常规交易场景。

5. 运行环境与部署教程
5.1 基础运行环境
- 操作系统：Windows 10 / Windows 11
- 运行语言：Python 3.9及以上稳定版本
- 接口支持：兼容所有OpenAI协议大模型API（DeepSeek、通义千问、GPT等）
- 网络要求：正常外网环境，可稳定访问行情API与大模型接口
5.2 依赖安装
在项目根目录打开终端，执行以下命令安装全部依赖：
pip install -r requirements.txt
5.3 系统启动流程
1. 启动量化交易核心程序：在项目根目录执行命令 python ai-trader/v3_main.py，系统自动初始化、加载配置、启动双AI轮询与风控监听。
2. 启动Web监控面板：进入面板目录，执行命令 cd trading-dashboard && python server.py，启动可视化服务。
3. 参数配置：浏览器访问 http://localhost:8000，在前端页面填写大模型API密钥，完成配置后系统自动正常运行。
6. 数据持久化机制
系统采用「数据库+本地文件双存储」模式，保障数据不丢失、可追溯：
- 交易记录、持仓历史、盈亏数据、系统日志统一存储在SQLite数据库，支持长期复盘与数据统计。
- 持仓状态、收益快照、系统配置等临时数据以本地文件形式缓存，程序重启后可自动恢复运行状态，无需重新初始化。
- 所有本地缓存、日志、数据库文件已配置忽略提交，不会上传至代码仓库，保障数据安全与代码整洁。
